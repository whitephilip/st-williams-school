# St William's Primary and Secondary School — Website Starter

This is **Phase 1: responsive public website and portal interface prototype**.

## Included
- Responsive public homepage
- About, academics, admissions, portal and contact sections
- Mobile navigation
- Portal-selection dialog for administrator, teacher, student and parent
- Primary 1–6, JSS 1–3 and SSS 1–3 displayed
- No external libraries required

## Important security note
The portal sign-in window is a demonstration only. It is **not authentication** and must not be used for real accounts or passwords. No credentials are sent or stored. Firebase authentication, role permissions, database rules, result workflows and payment verification have not been connected yet.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a more realistic local preview, use a simple local web server or open the folder in your preferred code editor.

## Deploy the public prototype
You can upload the project folder to a GitHub repository and connect it to Netlify or Firebase Hosting. Do not publish private student data, credentials, service-account keys, or payment secrets.
